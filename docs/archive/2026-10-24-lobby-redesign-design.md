# สเปก: ออกแบบหน้าล็อบบี้ใหม่ (BOF v0.7)

วันที่ 2026-10-24 · สถานะ: รอผู้ใช้ตรวจ

## 1. เป้าหมาย

หน้าล็อบบี้ปัจจุบันมีข้อมูลน้อย (Hero + การ์ดเมนู 3 ใบ) ทั้งที่เกมมีการ์ด 39 ใบ 3 เด็ค และระดับความหายาก 4 ระดับ
รอบนี้เปลี่ยนล็อบบี้เป็นหน้ายาวเลื่อนลงที่บอกว่าเกมคืออะไร มีอะไรให้เล่น และเริ่มเล่นได้ภายในคลิกเดียว

- **ผู้ใช้หลัก:** ทั้งคนใหม่ที่เพื่อนส่งลิงก์มา (น้ำหนักมากกว่าเล็กน้อย) และผู้เล่นประจำ
- **สำเร็จเมื่อ:** คนใหม่อ่านจอแรก 5 วินาทีแล้วบอกได้ว่านี่คือเกมการ์ดดวลบนเบราว์เซอร์และกดเล่นได้ทันที ·
  เพื่อนที่มีรหัสห้องเข้าห้องได้จากจอแรกโดยไม่เปิด modal · ใช้งานได้ดีที่ความกว้าง 390px
- **นอกขอบเขต:** ข้อเสนอ 5 (สอนกติกา), 7 (เล่นต่อ/เด็คล่าสุด), 8 (การ์ดประจำวัน), 9 (ตัวอย่างกระดาน), 10 (ข่าวอัปเดต) ·
  กระดานเล่นเกม, modal และ Deck Builder ไม่เปลี่ยนหน้าตา

## 2. ทิศทางศิลป์

ที่มา: `ui-ux-pro-max` (design system) + `design-taste-frontend` (direction sheet: `.taste-skill/direction.json`, seed 1102933145)

- **Direction:** Colour chapters — ทุกส่วนเป็นพื้นสีเรียบเต็มความกว้าง สูงอย่างน้อย ~90svh ชนกันโดยไม่มีเส้นคั่น
- **แนวคิด:** ในหน้านี้ เด็คจิต เด็คเหนือ และเด็ควันสิ้นโลก กลายเป็น 3 บทสี และเด็คที่ผู้เล่นเลือกจะเปลี่ยนสีของเวที
- **Live thing:** ส่วนเลือกเด็ค (§5.3) — กดชื่อเด็ค เห็นการ์ดจริงของเด็คนั้น แล้วกด "เล่นเด็คนี้"
- **Redraw ที่ทำ:**

  - stats: Figure set by a slider → Total and its receipt เพราะเกมไม่มีตัวเลขที่ผู้เล่นอยากปรับ แต่มียอดรวมที่แยกรายการได้จริง
- **ไม่ใช้จาก ui-ux-pro-max:** ชุดสีม่วง/ชมพูแดง (ขัดกฎห้ามม่วง) และฟอนต์ Russo One / Chakra Petch (ไม่มีอักษรไทย)

## 5. รายละเอียดแต่ละส่วน

### 5.0 Hero — Tabbed folder stack

- แถวบน 24px: wordmark (SVG ดาบไขว้ + "MY CARD TCG") ตรงกลาง · ลิงก์ข้อความขวาสุด "คลังการ์ด" (เปิด Card List) ·
  ลิงก์ซ้ายสุด "จัดเด็ค" (เปิด Deck Builder)
- `h1` "MY CARD TCG" บรรทัดเดียว ตรงกลาง `clamp(64px, 10vw, 160px)` · ใต้หัวข้อ 32px มีประโยคเดียว 20px:
  "เกมการ์ดดวลฟรีบนเบราว์เซอร์ 3 เด็ค 39 การ์ด ไม่ต้องติดตั้ง ไม่ต้องสมัคร"
- ตั้งแต่ 51% ของความสูงลงไป: แฟ้ม 5 แฟ้ม กว้าง 86vw ซ้อนเหลื่อมกัน 64px แต่ละแฟ้มมีแถบ (tab) รูปคางหมูสูง 40px ตัดด้วย
  `clip-path: polygon()` อยู่ตำแหน่งแนวนอนต่างกัน แถบเป็นลิงก์เลื่อนไปยังส่วนนั้น และใช้สีพื้นของส่วนนั้น:
  ภาพรวม (paper) → เด็ค (deck-jit) → การ์ด (paper-2) → วิธีเล่น (navy-2) → **เล่นเลย (gold, แฟ้มหน้าสุด เปิดอยู่)**
- แฟ้มหน้าสุดล้นขอบล่างของจอ ภายในมี:
  - ซ้าย: ปุ่มหลัก "ดวลกับเพื่อน" (gold → เปิด `#pvp-room-modal`) · ปุ่มรอง "เล่นกับบอท" (เปิด AI setup เดิม)
  - ใต้ปุ่ม: ฟอร์มเข้าห้อง — label ที่มองเห็น "มีรหัสห้องจากเพื่อน?" + `input` (`inputmode="numeric"`, `maxlength="4"` — รหัสจริงเป็นเลข 4 หลัก)
    + ปุ่ม "เข้าร่วม" → เรียก `joinPvpRoomAsGuest(code)` โดยตรง · ช่องว่างหรือไม่ใช่เลข 4 หลักแสดงข้อความใต้ช่อง ไม่ใช้ `alert` (เช็กก่อนเรียก)
  - ขวา: การ์ดลีดเดอร์ 3 ใบ (L01, L02, L03) ขนาดใหญ่ เรียงเหลื่อมกัน มี holo effect เมื่อชี้ (เฉพาะ `hover: hover`)
- ดาว (canvas เดิม) อยู่เฉพาะพื้นที่ Hero
- **มือถือ:** หัวข้อ 15vw สองบรรทัดได้ · แฟ้มเริ่มที่ 48svh เหลื่อม 52px แถบ 32px · แฟ้มหน้าสุดมีปุ่มเต็มความกว้าง ·
  การ์ดลีดเดอร์ 3 ใบเรียงแถวเล็กลงใต้ฟอร์ม

### 5.2 เลือกเด็ค (live thing) — Output index, live sheet

- `h2` "เลือกเด็คของคุณ"
- ซ้าย (คอลัมน์ 1–5): ชื่อเด็ค 3 ชื่อเป็น `<button>` ขนาด `clamp(36px, 4vw, 64px)` · ที่เลือกอยู่ใช้สีเต็ม อีกสองชื่อสีจาง ·
  `aria-pressed` บอกสถานะ
- ขวา (คอลัมน์ 7–12): เวทีสูง 88svh พื้นสีเด็คที่เลือก แสดง:
  - การ์ดลีดเดอร์ใหญ่ + การ์ดในเด็ค (ภาพจริง ไม่ซ้ำ) เรียงเหลื่อม ล้นขอบล่างของเวที
  - ชื่อลีดเดอร์ · HP 6 · จำนวนการ์ด 21 ใบ · สไตล์การเล่น 1 ประโยค:
    - **เด็คจิต** (ลีดเดอร์ มายฮีโร่ เดจิต): "เสริมพลังยูนิทแล้วบุกให้แรงที่สุดในเทิร์นเดียว"
    - **เด็คเหนือ** (ลีดเดอร์ ขุนเหนือ): "ส่งไพร่และทหารลงสนามให้ครบทัพ แล้วชุบกลับจากนรกไม่รู้จบ"
    - **เด็ควันสิ้นโลก** (ลีดเดอร์ วันสิ้นโลก): "ปลุกยูนิทจากนรก แล้ววิวัฒน์สู่ร่างแห่งอนาคต"
  - ปุ่ม "เล่นเด็คนี้" → ตั้ง `currentDeckConfig = { leaderId, mainDeck: [...getDefaultDeckForLeader(leaderId)] }`
    (เฉพาะในหน่วยความจำ **ไม่เขียนทับ** เด็คที่บันทึกไว้ใน `localStorage`) แล้วเปิดตัวเลือก "ดวลกับเพื่อน / เล่นกับบอท"
    ซึ่งเป็น dialog เล็กใหม่ที่เรียก flow เดิมของสองปุ่มใน Hero
  - ลิงก์ "ดูทั้ง N ใบในเด็ค" → เปิด Zone Viewer เดิมกรองเฉพาะการ์ดของเด็คนั้น
- ข้อมูลเด็คดึงจาก `CARD_DATABASE` + `getDefaultDeckForLeader()` · สไตล์การเล่นเป็นข้อความคงที่ใน HTML
- **มือถือ:** ชื่อเด็คเป็นแถวเลื่อนแนวนอน 22px (scroll-snap) · เวทีเต็มความกว้าง 70svh
- **ไม่มี JS:** เวทีแสดงเด็คจิตเป็นค่าเริ่มต้น และปุ่มยังเป็นปุ่ม

## 6. Motion (GSAP 3.12.5 core, `vendor/gsap.min.js`)

`js/lobby-motion.js` เขียนใหม่ **คง API เดิม** `window.LobbyMotion = { start, stop, isRunning, isPaused, ... }`
และพฤติกรรมเดิม: หยุดเมื่อเข้าเกม · พักเมื่อเปิด modal แล้วเล่นต่อ · ไม่ซ้อนเมื่อ start ซ้ำ · `lm-pre` กันค้าง 1.5 วินาที

- **ท่าเด่น (intro ≤ 2 วินาที):** `h1` แต่ละบรรทัดลอยขึ้นจากหลังเส้นฐาน (`yPercent: 110 → 0`, mask ด้วย `overflow: hidden`)
  0.9 วินาที `power4.out` บรรทัดที่สองตามมา 0.11 วินาที → ประโยครองค่อยๆ ปรากฏ → แฟ้มเลื่อนขึ้นซ้อนกันทีละแฟ้ม
  (`y: 80 → 0`, stagger 0.07) · คลิกระหว่าง intro = ข้ามไปสถานะสุดท้าย · กลับมาล็อบบี้ซ้ำใช้ intro สั้น (`sessionStorage` เดิม)
- **เข้าส่วน:** `IntersectionObserver` (threshold 0.2) → หัวข้อ → ข้อความ → ภาพ `y: 24 → 0` + `autoAlpha`
  stagger 0.08 เล่นครั้งเดียว · ไม่ซ่อนเนื้อหาด้วย CSS ถ้า JS ไม่ทำงาน
- **สลับเด็ค:** สีเวทีผ่าน CSS variable `--stage` 0.4 วินาที · การ์ดเดิม `autoAlpha → 0` 0.2 วินาที ·
  การ์ดใหม่ `y: 40 → 0` stagger 0.05 · `overwrite: 'auto'` กันกดรัว
- **Feedback:** ปุ่มกด `scale 0.97` (≤ 80ms) · hover ยก `y: -4` ผ่าน `gsap.quickTo` · focus ring มองเห็นชัด
- **ภาพเคลื่อนไหว:** holo shimmer บนการ์ดลีดเดอร์และการ์ด Legend (ใช้ `holo.js` เดิม) · ดาวใน Hero (canvas เดิม)
- **Reduced motion:** `gsap.matchMedia()` → แสดงสถานะสุดท้ายทันที ไม่มีการเลื่อน ดาวไม่ขยับ
- ใช้แค่ `transform` และ `opacity` (เทสต์ T4 เดิมตรวจไว้)
- ไม่เพิ่ม ScrollTrigger หรือไลบรารีใหม่

## 9. ความเสี่ยง

- **inspector ต้องการ "ภาพจริง ≥ 4"** — ภาพการ์ด 39 ใบนับเป็นภาพจริง ผ่านแน่นอน
- **ภาพการ์ดรวม 45MB** — แกลเลอรีใช้ lazy load และโหลดแค่ ~12 ใบ · Hero โหลดลีดเดอร์ 3 ใบ
- **id เดิมที่โค้ดอื่นพึ่ง** — คงไว้ตามตาราง §7 และตรวจด้วยเทสต์ทุกชุด
